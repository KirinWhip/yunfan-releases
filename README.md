# 云帆（Yunfan）安装包

这个仓库只放 **云帆** 的安装包和在线更新用的文件，**不含源代码**。

云帆是给跨境卖家用的 AI 独立站工作台：连上 Shopify / WordPress 店铺，AI 装修首页和整站、上架商品（本地文件夹和 1688）、去掉商品图上的中文、店铺体检。大模型用你自己的密钥（DeepSeek、阿里百炼等）。

## 下载安装

到右边的 **Releases**，下载最新版里的 `Yunfan_版本号_x64-setup.exe`，双击安装（Windows 10 / 11）。

装好后软件会每天自动查一次新版本，有新版时「设置」旁边会亮一个点，点「更新并重启」就行，店铺和草稿都不受影响。

- `latest-cdn.json`：在线更新清单（国内镜像用）

现在是**内测版**：全部功能免费用，遇到问题在软件「设置 → 导出诊断包」，发给我们。
